# Employee Payroll System

## Project Overview
The Employee Payroll System is a Core Java-based application designed to manage employee payroll processing.

This project demonstrates important Java concepts such as Object-Oriented Programming (OOP), inheritance, exception handling, and file handling.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling

## Project Structure

```text
EmployeePayrollSystem/
│
├── Employee.java
├── Manager.java
├── Main.java
├── EmptyInputFileException.java
├── InvalidRecordException.java
├── InvalidSalaryException.java
├── InvalidTaxRateException.java
├── InvalidTeamSizeException.java
│
├── employees.txt
├── errors.txt
└── payroll_report.txt
```

## Key Concepts Demonstrated
- Classes and Objects
- Inheritance
- Exception Handling
- Custom Exceptions
- File Handling
- Input Validation

## Input and Output Files
- `employees.txt` – Employee input data.
- `errors.txt` – Error information.
- `payroll_report.txt` – Payroll report output.

## How to Run
1. Clone or download this repository.
2. Open the project in a Java IDE such as Eclipse or IntelliJ IDEA.
3. Compile the Java source files.
4. Run the `Main.java` file.
